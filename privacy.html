Privacy Policy

Last updated: October 31, 2026

hermes is a private personal assistant used only by its owner. This policy explains how it handles Google user data.

Data accessed

  • Gmail (read-only): message headers and content, to summarize the owner's mail.
  • Google Calendar: the owner's calendars and events, to show the schedule and to add or change events when the owner asks.

hermes does not request permission to send, delete, or modify email.

How data is used

Data is used only to provide features the owner requests. It is not used for advertising, sold, or used to train AI models.

Storage and sharing

Access tokens and any working data are stored only on the owner's own private server. To answer a request, the relevant text may be sent to the AI model provider the owner has configured, solely to generate that answer. Data is not shared with anyone else.

Limited Use

hermes's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time at myaccount.google.com/permissions.
